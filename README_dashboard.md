# Outdoor Rug - Category Intelligence Dashboard

## Overview
This repository contains a unified, interactive **Category Intelligence Dashboard** for the Outdoor Rug segment. The dashboard is designed to provide e-commerce strategists, merchandisers, and product developers with a comprehensive, at-a-glance view of market health, competitive dynamics, and actionable opportunities.

The report aggregates data across major retailers (Wayfair, Amazon, Walmart) to deliver actionable insights on pricing, product assortment, trending micro-segments, and potential market risks.

## Files Included
* `Outdoor_Rug_Dashboard_2026-09-05.html`: A self-contained, fully styled HTML dashboard. It utilizes HTML, inline CSS, and vanilla JavaScript to create a seamless, interactive user experience without requiring external frameworks or servers.

## Dashboard Features & Sections
The dashboard features a persistent sidebar for easy navigation across six primary modules:

1.  **Executive Overview (📊):** A high-level summary of category health, key trends (the shift towards "indoor-outdoor fluidity"), competitive positioning, key suppliers, critical alerts, and top priority actions.
2.  **Market & Trends (📈):** Details market size projections ($4.22B in 2025 to $6.85B in 2033), analyzes dominant micro-segments (e.g., Modern Minimalist, Bohemian Botanical), and presents dominant color palettes and visual moodboards.
3.  **Competitive Intel (⚔️):** Provides a side-by-side analysis of Amazon, Walmart, and Wayfair, including pricing distribution (budget vs. premium), assortment strategies, and a detailed competitor comparison matrix.
4.  **Opportunity Radar (🎯):** Identifies and categorizes market whitespace (e.g., $300+ luxury oversized rugs, sustainable options) based on priority and potential impact, complete with a price gap heatmap.
5.  **Risk & Diagnostics (⚠️):** Highlights potential threats such as value segment commoditization, sustainability concerns, and review/social proof deficits, offering mitigation strategies for each.
6.  **Action Center (✅):** A prioritized checklist of strategic initiatives (Quick Wins vs. Strategic Plays) designed to directly address the insights uncovered in the report.

## Interactive Elements
* **Tabbed Navigation:** Seamlessly switch between different analytical views using the sidebar.
* **Expandable Risk Cards:** Click on risk alerts in the Diagnostics tab to view detailed mitigation strategies.
* **Search Functionality:** Use the top bar search input to quickly filter through the dashboard's text content.
* **Print/Export:** A dedicated "Export PDF" button that optimizes the layout for printing or saving as a PDF document.

## How to View
1. Clone or download this repository to your local machine.
2. Double-click the `Outdoor_Rug_Dashboard_2026-09-05.html` file to open it in any modern web browser (Chrome, Firefox, Safari, Edge).
