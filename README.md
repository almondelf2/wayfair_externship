# Wayfair n8n AI Agent Engineering Externship

## Project Overview
This repository contains the deliverables for the **Wayfair n8n AI Agent Engineering for Business Intelligence** externship. Throughout this 8-week project, the core objective was to step into the role of an AI Agent Developer at Wayfair, utilizing workflow automation and large language models to build intelligent agents capable of surfacing actionable e-commerce insights. 

By analyzing thousands of products and real-time market signals, these AI agents track trending rug styles, monitor competitor launches, and generate marketing content ideas—all aggregated into a unified business intelligence dashboard designed for Wayfair's category management team.

## Tools & Technologies Used
* **n8n:** Workflow automation software used to build and orchestrate the AI agents.
* **Google Gemini & Mistral AI:** Large Language Models (LLMs) used for data extraction, trend analysis, and natural language generation.
* **Google Sheets / HTML Dashboards:** Used to host live, auto-updating data visualizations and intelligence reports.
